# All-in-One Runtime Installer
Download and install all latest Microsoft Visual C++, .NET Frameworks (SDK) and DirectX redistributable in one click (Downloaded From Microsoft Website)

## Usage
1. Download the latest release package from here.
2. Extract the package to your desired location.
3. Run `Install Auto.bat` script as administrator.

## Note
Do not rename any files, as this will prevent the script from running correctly.
